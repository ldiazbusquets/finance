# Report logos

Drop a company's logo here, named after its ticker, and its research report shows it in the top-right corner:

- `PLTR.svg`, `MU.png`, `AMD.webp` ... (SVG first, then PNG, then WebP)
- Private companies use their page key: `ANTHROPIC`, `OPENAI`, `ANDURIL`, `BLOOMBERG`
- A transparent background works best; the logo sits on a small ivory tile so dark logos stay visible in the dark theme.

Without a file, the report shows the ticker instead. No rebuild is needed: upload the file and the page picks it up.
